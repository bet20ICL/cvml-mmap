Uniform cubic B-spline as a continuous-time trajectory

A trajectory stored as 8 control points can be queried at any time — e.g. at the irregular timestamps of a camera, while the control points sit on a regular knot grid (Δt = 1). Each query blends just 4 neighbouring control points. Drag the points; hover the teal camera markers.

Trajectory

spline p(t) control polygon camera timestamps SE(2) position

Pose mode: each control point is a pose Tk = (θk, ck); drag the orange handles to rotate. The robot (triangle) is T(t) = Ti · Πj=1..3 exp( B̃j(u) · log( Ti+j−1−1 Ti+j ) ), evaluated on the Lie group SE(2), so position and heading are interpolated jointly (the orange dashed path can deviate from the purple one when headings disagree with the path). With all headings equal it reduces exactly to the plain spline. SE(3) works the same way — just swap in the so(3)/se(3) exp and log maps.

Weights at the current time

Basis functions over one segment, u ∈ [0, 1]

The same four curves are reused in every segment (that is what "uniform" means). At u = 1 the weights [0, 1/6, 2/3, 1/6] equal the u = 0 weights of the next segment shifted by one control point, which is why the curve is C² continuous across knots.

The math
segment i = min(⌊t⌋, 4), u = t − i ∈ [0, 1) p(t) = B0(u)·c_i + B1(u)·c_{i+1} + B2(u)·c_{i+2} + B3(u)·c_{i+3} B0 = (1−u)³/6 B1 = (4 − 6u² + 3u³)/6 B2 = (1 + 3u + 3u² − 3u³)/6 B3 = u³/6 Cumulative form (the one that generalises to Lie groups): p(t) = c_i + Σ_{j=1..3} B̃_j(u)·(c_{i+j} − c_{i+j−1}) B̃1 = (5 + 3u − 3u² + u³)/6 B̃2 = (1 + 3u + 3u² − 2u³)/6 B̃3 = u³/6 (B̃_j = Σ_{k≥j} B_k) SE(2): exp(vx, vy, ω) → R = rot(ω), t = V(ω)·[vx, vy] V(ω) = [[sinω/ω, −(1−cosω)/ω], [(1−cosω)/ω, sinω/ω]] log(T) → ω = atan2(R), [vx, vy] = V(ω)⁻¹·t
